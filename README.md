❤️ Heart Disease Prediction using Machine Learning

A Machine Learning web application that predicts the likelihood of heart disease based on patient clinical data. The project includes data preprocessing, exploratory data analysis (EDA), model training, evaluation, and deployment using Streamlit.

Features

- Predicts heart disease risk in real time.
- Performed data cleaning, preprocessing, feature encoding, and scaling.
- Compared Logistic Regression, KNN, Naive Bayes, Decision Tree, and SVM models.
- Achieved 88.6% accuracy using the K-Nearest Neighbors (KNN) model.
- Built and deployed an interactive Streamlit web application.

Dataset

- 918 patient records
- 12 clinical features
